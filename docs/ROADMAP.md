# Roadmap

## Phase A — Foundation (current)
- responsive web decision dashboard;
- dynamic user constraints;
- explainable deterministic decision engine;
- provider registry;
- VectorStore / GraphStore contracts;
- recurring sync endpoint;
- OpenAI provider boundary;
- Vercel-ready deployment.

## Phase B — Real market observations
- YouTube Data API collector;
- channel OAuth and private Analytics/Reporting collectors;
- public competitor snapshots;
- RSS/news/Wikipedia adapters;
- quota and provenance ledger;
- normalized source/topic/entity model.

## Phase C — Persistent memory
- PostgreSQL schema;
- pgvector embeddings and semantic retrieval;
- short/medium/long memory policies;
- feedback and actual-outcome learning.

## Phase D — Diffusion graph
- Neo4j adapter;
- source/topic/platform/country nodes;
- temporal edges with lag, weight, decay and confidence;
- source-leading score;
- cross-platform/cross-country transport estimates.

## Phase E — Regime forecasting
- demand/supply time series;
- PRE_TREND / ACCELERATION / PEAK / DECLINE inference;
- Hawkes-process experiments for cross-excitation;
- survival / half-life models;
- production-adjusted opportunity;
- attention-supply gap and winner concentration.

## Phase F — Creator decision intelligence
- channel-specific baselines;
- expected views/engagement distributions;
- uncertainty intervals;
- recommendation vs abstain decision;
- standalone-potential score versus trend-capture score;
- experiments and post-publication learning.

## Invariants
- no prohibited scraping of YouTube;
- no future leakage in pre-publication models;
- no metric presented as real if it is synthetic or inferred;
- every important score exposes evidence, uncertainty and risks;
- no publishing action without explicit authorization.
